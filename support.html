Support

TinyOps Mermaid is in pilot. Support is provided directly by TinyOps during European business hours.

Open a support request

Use the guided GitHub support form for product questions, defects, and feature requests. You can also contact TinyOps by email at marc-hager@outlook.com.

Public channel: never include Mermaid source, page content, personal data, tenant URLs, access tokens, attachment identifiers, screenshots containing confidential information, or security vulnerabilities.

For a suspected vulnerability, use the private security reporting process.

What to include

  • problem summary and expected behavior;
  • browser name and version;
  • Confluence Cloud and app context;
  • diagram type and approximate node count without sensitive source;
  • PDF or Word when the problem concerns export;
  • safe reproduction steps using sample data.

Response targets

Support hours are Monday–Friday, 09:00–17:00 Europe/Berlin, excluding local public holidays.

PriorityExampleInitial response target

These are response targets, not guaranteed resolution times. Severity may be adjusted after triage.

Quick troubleshooting

  1. Open the macro editor and confirm that the live preview renders.
  2. Check the syntax error and character counter.
  3. Confirm the export status before saving.
  4. Publish the page before running a native Confluence export.
  5. Try the smallest safe sample that reproduces the behavior.

See the export documentation for snapshot, pagination, and fallback behavior.
