Privacy policy

TinyOps Mermaid is designed so diagram content remains within the Atlassian environment selected by the customer.

Effective date: 28 September 2026 · Product stage: Pilot

Summary

TinyOps Mermaid does not operate an external application server, analytics service, advertising service, or third-party diagram renderer.

The app does not intentionally transmit Mermaid source, rendered diagrams, Confluence page content, user identity, or usage analytics outside Atlassian.

Data processed

To provide the macro, TinyOps Mermaid processes the following data inside the browser and Atlassian Forge environment:

  • diagram title and Mermaid source;
  • selected theme and display mode;
  • sanitized SVG used for the interactive preview;
  • PNG snapshot segments used for PDF and Word export;
  • Atlassian attachment identifiers and a content hash used to reuse valid snapshots.

The app does not request diagram content for a purpose unrelated to rendering, export, or macro configuration.

Storage and retention

Macro configuration is stored with the Confluence page. Export snapshots are stored as attachments on that same page. TinyOps does not maintain a separate application database for this content.

Retention follows the customer's Confluence page and attachment lifecycle, including Atlassian versioning and deletion behavior. Uninstalling the app does not automatically delete page content or attachments already stored in Confluence.

Sharing and subprocessors

TinyOps Mermaid does not send product data to an external subprocessor. Atlassian provides Confluence Cloud, Forge runtime, storage, and Media Services under the customer's existing Atlassian relationship.

This documentation website

This website is hosted on GitHub Pages. It contains no analytics, advertising, cookies, forms, or externally loaded fonts and scripts. GitHub may process technical request data when serving the site under its own terms.

Privacy questions

The provider responsible for TinyOps Mermaid is Marc Hager. Full provider information is available in the legal notice.

For privacy questions, email marc-hager@outlook.com or open a support request in the public repository. Do not include personal, confidential, or diagram data in a public issue. For sensitive security information, use the private reporting channel.
