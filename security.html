Security

TinyOps Mermaid uses strict local rendering, sanitization, bounded image generation, and minimal Atlassian permissions.

Architecture

  • No network egress: no external rendering endpoint or vendor backend receives diagram content.
  • Browser and Forge processing: rendering runs inside the Forge Custom UI context.
  • Atlassian storage: macro configuration and export attachments remain on the Confluence page.
  • Minimal permission: the app declares write:confluence-file to create export attachments.

Rendering controls

ControlImplementation
Mermaid securityStrict security mode and an allowlisted configuration
Input bound20,000-character source limit
SVG sanitizationDOMPurify SVG profile plus removal of scriptable and external content
Image bound4,096-pixel side and 16-million-pixel canvas-area limits
Attachment referencesValidated Atlassian Media identifiers only
Error handlingSanitized user-facing parser errors

Inline style support is limited to the styles Mermaid requires to render SVG. The Forge content-security policy does not allow external network connections for diagram rendering.

Dependencies and releases

Production dependencies are locked, automated tests cover normalization, sanitization, attachment reuse, pagination, and export-resource behavior, and dependency audits are part of release verification. Releases require a successful production build and relevant automated tests.

Report a vulnerability

Do not disclose security vulnerabilities in a public GitHub issue.

Use GitHub's private vulnerability reporting form. Include affected behavior, reproducible steps, impact, and a safe proof of concept. Remove secrets, access tokens, customer content, and personal data.

We will acknowledge a valid report within two business days, investigate according to severity, and coordinate disclosure after a fix is available. This target is not a guarantee of resolution time.

Current scope

This statement covers TinyOps Mermaid for Confluence Cloud. It does not cover Atlassian's own platform, Confluence, Forge, GitHub Pages, or software outside the TinyOps app.
