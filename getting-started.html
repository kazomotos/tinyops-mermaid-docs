Get started

Create a Mermaid diagram, check it while you write, and save an export-ready version to a Confluence page.

Pilot status: installation is currently provided directly to approved pilot sites. A public Marketplace installation link will be added after launch review.

Add the macro

  1. Open a Confluence Cloud page in edit mode.
  2. Type /mermaid and select TinyOps Mermaid Diagrams.
  3. Give the diagram a descriptive title.
  4. Write Mermaid syntax or select a starter template.

Review and save

The preview updates from the same source that will be stored with the macro. Syntax errors appear without exposing raw internal exception details. When the preview and export snapshot are ready, save the macro.

A green PDF & Word snapshot ready status means the app has prepared the attachment used by Confluence export.

Navigate a large diagram

  • Use zoom controls for detailed inspection.
  • Switch to detail mode when the graph needs horizontal space.
  • Use fullscreen for focused review.
  • Download SVG or PNG when you need a standalone asset.
