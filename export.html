PDF and Word export

TinyOps Mermaid prepares static snapshots before save so Confluence export does not depend on running the interactive viewer.

Export pipeline

  1. The browser renders Mermaid as sanitized SVG inside the Forge app.
  2. The app creates bounded PNG snapshot segments for export.
  3. Snapshots are stored as attachments on the same Confluence page.
  4. The export macro references Atlassian Media Services identifiers, not an external URL or embedded data URI.
  5. Confluence includes those snapshots in PDF and Word output.
The current production path uses page attachments for both PDF and Word. Diagram content is not sent to a third-party renderer.

Large diagrams

Canvas creation is bounded to reduce browser memory and denial-of-service risk. When a diagram would exceed the safe output area, TinyOps creates multiple readable segments instead of a single oversized bitmap.

ConstraintBehavior
Maximum source length20,000 characters
Maximum canvas side4,096 pixels
Maximum canvas area16 million pixels
Oversized outputSplit into ordered export segments

Fallback behavior

If TinyOps cannot produce a safe image snapshot, the export includes the diagram title and Mermaid source instead of silently omitting the content. The editor shows a fallback status before save.

Do not ignore a fallback status. Fix the syntax or reduce diagram complexity, save again, and re-run the export.

Verify an important export

  1. Confirm that the editor shows an export-ready status.
  2. Publish the Confluence page.
  3. Run the native Confluence PDF or Word export.
  4. Check labels, ordering, page boundaries, and legibility at normal zoom.

For a reproducible support report, include the export format, approximate node count, diagram type, browser, and whether the editor showed ready or fallback. Do not include confidential diagram source in a public issue.

Direct downloads

SVG and PNG downloads from the interactive macro are separate from Confluence page export. SVG preserves vector detail; PNG is useful for documents and systems that do not support SVG.
