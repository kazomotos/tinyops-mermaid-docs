# Security policy

Do not disclose a suspected vulnerability in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/kazomotos/tinyops-mermaid-docs/security/advisories/new) and include the affected behavior, reproducible steps, impact, and a safe proof of concept. Remove secrets, access tokens, customer content, and personal data.

TinyOps aims to acknowledge a valid report within two business days. See the public [security overview](https://kazomotos.github.io/tinyops-mermaid-docs/security.html) for architecture, scope, and controls.
